# Security Policy

## Supported Versions

This repository currently tracks the active documentation set only. Security updates are applied to the latest version of the repository contents.

## Reporting a Vulnerability

If you discover a security issue, please do not open a public issue.

Instead, contact the repository maintainer privately and include:

- A description of the issue
- The affected files or areas
- Steps to reproduce, if applicable
- Any suggested fix or mitigation

## Response Timeline

We will review security reports as soon as possible and respond with next steps.

## Scope

This security policy applies to repository content, workflows, and related project configuration.
