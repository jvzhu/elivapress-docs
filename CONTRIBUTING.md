# Contributing

Thanks for helping improve ElivaPress documents.

## Guidelines

- Keep changes focused and easy to review.
- Use clear file names and folder organization.
- Place source documents in `documents/source/`.
- Place supporting media in `documents/assets/`.
- Avoid committing temporary, generated, or unrelated files.

## Suggested workflow

1. Create a branch for your changes.
2. Make and test your updates.
3. Open a pull request with a short description of what changed.
4. Request review if needed.

## File standards

- Use descriptive titles and filenames.
- Prefer plain, maintainable document formats.
- Keep the repository structure consistent.

## Questions

If anything is unclear, add notes in the PR description.
