# ElivaPress Documents

This repository stores ElivaPress-related documents, source files, and supporting assets.

## Structure

- `documents/source/` — original document files such as PDF, DOCX, or TXT
- `documents/assets/` — images, cover art, and other supporting assets

## Usage

Add new documents under the appropriate folder and keep filenames descriptive.

## Notes

- Keep source documents organized by type or topic.
- Include only files you have the right to publish or distribute.
