# Code of Conduct

## Our Pledge

We are committed to providing a welcoming and respectful environment for everyone who participates in this project.

## Expected Behavior

Please help create a positive community by:

- Being respectful and considerate
- Using welcoming and inclusive language
- Accepting constructive feedback gracefully
- Focusing on what is best for the project
- Showing empathy toward other contributors

## Unacceptable Behavior

Examples of unacceptable behavior include:

- Harassment or discriminatory language
- Personal attacks or insults
- Deliberate trolling or disruption
- Publishing private information without permission
- Any behavior that creates an unsafe or hostile environment

## Scope

This Code of Conduct applies in all project spaces, including:

- Pull requests
- Issues
- Discussions
- Commit messages
- Any communication related to the project

## Reporting Issues

If you experience or witness behavior that violates this Code of Conduct, please report it to the project maintainers.

## Enforcement

Project maintainers may take appropriate action in response to behavior that violates this Code of Conduct, including warnings, removal of content, or other necessary steps.

## Attribution

This Code of Conduct is adapted from common open source community guidelines.
