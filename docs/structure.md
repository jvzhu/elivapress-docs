# Directory Structure

```text
elivapress-docs/
├─ README.md
├─ CONTRIBUTING.md
├─ documents/
│  ├─ source/
│  │  ├─ README.md
│  │  └─ template.md
│  └─ assets/
│     └─ README.md
├─ docs/
│  └─ structure.md
└─ .gitignore
```

## Folder purposes

### `README.md`
Repository overview and basic usage instructions.

### `CONTRIBUTING.md`
Guidelines for contributing to the repository.

### `documents/source/`
Stores original document files.

### `documents/assets/`
Stores supporting media and attachments used by documents.

### `docs/structure.md`
Short reference for the repository layout.

### `.gitignore`
Excludes temporary, system, and editor-related files from version control.
